# TaskMate - To-Do List Application

A small web application developed for Software Engineering Assignment 01.

## Technologies
- HTML
- CSS
- JavaScript
- GitHub
- GitHub Actions
- GitHub Pages

## Features
- Add tasks
- Mark tasks as completed
- Delete tasks
- Clear completed tasks
- Task counter
- Local storage support

## DevOps Workflow
1. Develop the application locally.
2. Test it in a browser.
3. Push the source code to GitHub.
4. Make meaningful commits.
5. Run automated CI checks with GitHub Actions.
6. Fix errors if a CI check fails.
7. Deploy with GitHub Pages.
